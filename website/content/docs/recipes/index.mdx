The [concepts](/docs/concepts/two-layers) pages explain the model; these are the jobs people
actually sit down to do. Each one is self-contained — start from the closest match and adapt.

## Common jobs

| Recipe | What it covers |
|---|---|
| [Single-file avatar](/docs/recipes/avatar) | one file per owner, replacing the previous one, with a cropped variant |

## Files that aren't media

A report, a cache file, a file another library reads: use `@nestjs/storage` directly (`Storage`, `@InjectDisk()`, `serveFile()`, `uploadToDisk()`). See [File storage](https://docs.nestjs.com/application/file-storage) in the NestJS docs; nestjs-media adds nothing there.
